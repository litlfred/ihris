Workflow

How data moves through this folio: 17 skills, 40 kinds of data. It is drawn from what the skills declare, not by hand: each skill names its input and output contracts, each kind of data is defined once (src/schemas/skills/artefacts.schema.json), and QA checks that the Tools performing a skill cover its contract.
