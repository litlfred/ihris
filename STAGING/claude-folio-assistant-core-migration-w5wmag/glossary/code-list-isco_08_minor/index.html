The source gives no definitions, so every term is a candidate. 130 term(s) have exactMatch to ISCO-08 in ESCO (European Commission) by ValueSet identity: the ValueSet ihris-isco-08-minor binds this list to http://www.ilo.org/public/english/bureau/stat/isco/isco08/, so each code is that system's code. No ConceptMap records it; the basis was accepted by the owner's ruling of 2026-09-24 (ihris PR #19). The IRIs follow the publisher's pattern and were not dereferenced.
