Name matching only (src/tools/ingest_use_cases.py): a form matches a use case when the form's name, with underscores read as spaces, or a display name a module declares for it, occurs word for word in the use case's TITLE, after folding simple plurals on both sides. A shorter match inside a longer one is dropped. Nothing is inferred from meaning: an unmatched use case has `matches: null` until a person links it (AGENTS.md §7). Every link says `derivedBy: name-match`.
