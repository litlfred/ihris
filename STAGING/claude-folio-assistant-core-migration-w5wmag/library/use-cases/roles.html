Roles and actors (2009 use cases)

Each actor a 2009 report describes is a role in the iHRIS domain, declared in folio-assistant's scenarios graph kind (library/ihris-use-cases/scenarios/roles.json). Title and description are the report's own. A-ICE4 (Common) and A-PS6 (Qualify) are both “Any User”, and they are one role (owner, 2026-09-24). “Primary actor on” lists the use cases whose “Primary Actors” field names the role (scenarios/stories.json).
