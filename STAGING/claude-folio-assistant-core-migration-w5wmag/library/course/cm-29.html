Question 4 (match)

Match the following iHRIS-related terms or acronyms with their definitions.

statement answer
LAMP The architecture used for many web-based programs such as Moodle
Locale A pair (language, country) used in the iHRIS software to keep track of translations in various languages
Magic Data The place in the iHRIS software that holds information about modules, pages, forms, and reports
I2CE The name of the web framework on which the iHRIS software is built
Bazaar Software used for version control
SDMX-HD A format developed by the World Health Organization to facilitate the exchange of indicator definitions and data between information systems
Use Cases Documents used in development to describe a work process
Launchpad The website that hosts the iHRIS code and facilitates management of translations into other languages
