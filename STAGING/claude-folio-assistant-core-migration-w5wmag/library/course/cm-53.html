Data Standardization

1. Data Standardization

This module outlines:

  • a definition of data standardization
  • the importance and value proposition of using data standards in routine information systems
  • structures in place within iHRIS to assist with applying data standardization

2. Definition of Data Standardization

Data Standardization: The process of making all data of the same type conform to an established convention to ensure consistency and comparability.

3. Data Standards in Routine Information Systems

Routine systems are often comprised of data from multiple sources.

To aggregate information to produce meaningful reports, you must have data standards in place to put together all like information.

To use a fruit analogy:

  • all items defined as apples actually look and taste like apples and are indeed apples
  • ensuring this is true from the outset will help you gather all of the apples into one basket for counting and comparing or contrasting with other fruit

When data standards are not applied the data become meaningless.

4. Example of the Need for Data Standards

The following are all considered valid phone numbers in the United States:

  • (919) 321-1500
  • +1 919 321 1500
  • 321-1500
  • 01-919-321-1500
  • 1.919.321.1500

Without applying a data standard on how phone numbers should be captured, all of these phone number formats could be entered into the same phone number field.

In this example, 321-1501 is only valid if calling within the same geographic area of the United States; so the phone number is invalid and useless data.

5. Example of the Need for Data Standards

To avoid this issue, use an input mask that requires all phone numbers to be in a standard format such as country code + area code + phone number.

This will also prevent variations in individual interpretations by data clerks.

It will allow for flexibility in countries that have differing numbers of digits in mobile and landline numbers.

It ensures that phone numbers will be captured in the same format so the data will be meaningful.

6. iHRIS and Data Standards

iHRIS has a number of value lists that can be (and should be) defined prior to deploying the system.

The Administrator should work with the HR Manager to define these lists before beginning data entry in order to avoid problems with lack of standards, such as variations in job titles.

7. ISCO Standards

iHRIS Manage supports the international standard classification of occupations (ISCO) classification structure as defined by the International Labour Organization (ILO).

Adhering to the ISCO standards will enable an organization to standardize job classifications and compare data within the country, region, and globally.

8. ISCO Standards

If an organization does not already have a standardized job structure, the ISCO standards can be a guide.

The iHRIS Manage setup phase is an opportunity to map existing job structures to the ISCO standards to allow for easy aggregation and comparison across organizations.

The ISCO classifications are available on the Job Classification form.
