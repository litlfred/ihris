Working in Teams: Launchpad and Bazaar

iHRIS Administrator - Level I, © IntraHealth International, CC BY 4.0. Originally offered at hrhresourcecenter.org/elearning (CapacityPlus). Licence stated by its author, the folio owner, 2026-10-09.

1. Launchpad and Bazaar

Launchpad allows users to work on team projects: http://www.launchpad.net

Bazaar is a distributed version control system (D-VCS) that keeps track of changes in software source code and helps people work on it in teams.

2. Launchpad and Bazaar: SSH Key

Go to http://www.launchpad.net and create an account with a username you select.

Generate a ssh-key on your machine:

  • open a terminal
  • install ssh: sudo apt-get install openssh-client
  • generate a key: ssh-keygen -t rsa

When prompted, press Enter to accept the default file name for your key.

Enter a password (Optional).

The public key is stored in: ~/.ssh/id_rsa.pub

The private key is stored in: ~/.ssh/id_rsa.pub

3. Launchpad and Bazaar: SSH Key

Upload the ssh-key to launchpad:

  • browse to http://www.launchpad.net/~username
  • find SSH Keys with an exclamation point (!) in a yellow circle next to it
  • click the (!) and scroll down to "Add an SSH Key and a text box"
  • paste the public key into this text box:
  • in a terminal type: gedit ~/.ssh/id_rsa.pub &
  • copy and paste from gedit to the web browser
  • click "Import Public Key"

Import the ssh-key for each computer used.

4. Launchpad and Bazaar: Bazaar

bzr is the main command for the Bazaar software:

  • bzr init: create a "branch" to hold your code
  • bzr add: add files to your branch
  • bzr whoami: tell bzr who you are
  • bzr commit: change and "commit" code to your branch
  • bzr status: see what has not been commited
  • bzr log: see what changes have been made
  • bzr branch: make a copy of a branch

Install bzr: sudo apt-get install bzr bzrtool

5. Launchpad and Bazaar: Locations

Bazaar can work with files on your computer.

Launchpad has a Bazaar service you can use to host branches:

  • files are publically readable
  • control who can change the files by individual or teams
  • backs up source code
  • create a project on Launchpad to hold multiple branches: ihris-manage, i2ce, ihris-manage-lesotho
  • use the translation capabilities built into Launchpad

bzr operates effectively with Launchpad.

6. Launchpad and Bazaar: Teams

Launchpad uses teams to control who can modify code it stores under Bazaar.

If you are working with a group of people, you should all agree on who will be the team owner.

The team owner should create the team.

Every person should join this team.

To practice creating teams, use the test site: http://staging.launchpad.net/~his-workshop

7. Launchpad and Bazaar: Project

Launchpad uses projects to group related code (branches), manage software releases, translations, etc.

Create a project in Launchpad.

Launchpad is licensed under the GPL V3.

The Maintainer of the project assigns the teams by clicking the yellow exclamation point.

To practice creating projects, use the test site: https://staging.launchpad.net/his-helloworld-Z

8. Apache: helloworld.php

The owner creates a directory for the "trunk" of the Hello World web application such as: mkdir -p ~/helloworld/trunk

Create helloworld.php: gedit ~/helloworld/trunk/helloworld.php

Add the following code to helloworld.php: <?php echo "<p>hello his gathering</p>\n";

Make it available to apache web server: sudo ln -s ~/helloworld/trunk /var/www/helloworld

9. Bazaar: Initial Commit

The team owner needs to make the bzr branch and the intial commit: cd ~/helloworld/trunk bzr init bzr add bzr commit -m

10. Bazaar and Launchpad: Putting the Code on Launchpad

As the team owner, go to "Registers a Branch" at:

  • https://code.staging.launchpad.net/his-helloworld-Z
  • Owner: his-workshop
  • Name: trunk
  • Branch Type: hosted

Put the code on Launchpad: cd ~/helloworld/trunk bzr push --use-existing-dir lp://staging/~his-workshop/his-helloworld-Z/trunk bzr bind lp://staging/~his-workshop/his-helloworld-Z/trunk

11. Bazaar

Each team member can get a checkout of the code from Launchpad: mkdir ~/helloworld bzr branch lp://staging/~his-workshop/his-helloworld-Z/trunk

"bind" the code to Launchpad—all committed changes automatically go to Launchpad: cd ~/helloworld/trunk bzr bind lp://staging/~his-workshop/his-helloworld-Z/trunk

12. Bazaar and Launchpad: Commits

The team owner needs to make the initial commit.

Commit to the (unbound) branches means changes are only local and do not get pushed up to Launchpad automatically.

To put changes to code on Launchpad, use one of the following:

  • bzr checkout: use instead of bzr branch
  • bzr push: if you used bzr branch this will move committed code to launchpad one time only
  • bzr bind: changes a bzr branch to a bzr checkout
  • bzr info: tells you what is going on

13. Changing the Code

For example, if a team member wants to change the code to add a footer file: cd ~/helloworld/trunk gedit footer.php

Add the contents and save: echo "<b>Today is " . date("D, d M Y") . "</b>\n";

Edit the helloworld.php: gedit helloworld.php

Append the line to the end of the file and save.

Include("footer.php");

14. Committing the Changes

Commit the changes to Launchpad: cd ~/helloworld/trunk bzr add footer.php bzr commit -m "added footer"

To look at changes: https://code.staging.launchpad.net/his-helloworld-z

Team members may get the changes by: cd ~/helloworld/trunk bzr update

15. Renaming Files

To rename files, such as changing helloworld to an index for example: cd ~/helloworld/trunk bzr mv helloworld.php index.php bzr commit -m "Renamed helloworld.php to index.php"

Team members can get the changes: cd ~/helloworld/trunk bzr update
