CodeSystem: ISO 3166-1 Codes for the representation of names of countries and their subdivisions — Part 1: Country code

Official URL: urn:iso:std:iso:3166 Version: 0.1.0
Active as of 2022-08-23 Computable Name: ISO3166Part1
Other Identifiers: OID:1.0.3166.1

Copyright/Legal: ISO Maintains the copyright on the country codes, and controls it's use carefully. For futher details see the ISO 3166 web page: https://www.iso.org/iso-3166-country-codes.html

ISO 3166-1 establishes codes that represent the current names of countries, dependencies, and other areas of particular geopolitical interest, on the basis of country names obtained from the United Nations.

This Code system is referenced in the content logical definition of the following value sets:

  • Iso 3166 Part 1: 2 Letter Codes
