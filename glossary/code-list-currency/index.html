Glossary: currency

iHRIS 4.3.3 code list: currency: 162 terms, as W3C SKOS (JSON-LD). The `currency` code list as iHRIS 4.3.3 ships it by default: 162 codes from ihris-common/module/iso-currency. Each term's notation is the iHRIS record id and its label the record's `name`. The source gives no definitions, so every term is a candidate. The 4 sample record(s) illustrate one example deployment and are left out. 143 term(s) link to EU Publications Office authority table: currencies, from the verified ConceptMap currency-to-iso-4217 (equal only); the IRIs follow the publisher's pattern and were not dereferenced. It is one of the glossaries in the full glossary.
