Glossary: country

iHRIS 4.3.3 code list: country: 246 terms, as W3C SKOS (JSON-LD). The `country` code list as iHRIS 4.3.3 ships it by default: 246 codes from ihris-common/module/iso-country. Each term's notation is the iHRIS record id and its label the record's `name`. The source gives no definitions, so every term is a candidate. The 13 sample record(s) illustrate one example deployment and are left out. 245 term(s) link to EU Publications Office authority table: countries, from the verified ConceptMap country-to-iso-3166 (equal only); the IRIs follow the publisher's pattern and were not dereferenced. It is one of the glossaries in the full glossary.
