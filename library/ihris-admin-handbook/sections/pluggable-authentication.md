# Pluggable Authentication

With verison 4.0.3 of the iHRIS Suite we now provide a pluggable authentication module.

The authentication modules are:

- I2CE User Access (Default)
- DHIS User Access
- LDAP User Access
- LDAP Hybrid User Access

Security Note: There is a new administrator account created on the system. The user name is 'i2ce\_admin' and the password is the same password used for mysql database connection.
