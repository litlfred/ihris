# Section 1

In this section, you will learn about health information systems, in particular human resource information systems. You will be introduced to the iHRIS Suite of software and an overview of its architecture. Finally, you will install the Ubuntu operating system on your computer.

Tasks:

- Install Ubuntu and iHRIS
- Use of SSH, Gedit, xchat
- Create and run "hello world" type of PHP program running on webserver
