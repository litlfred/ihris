# Course Overview

**Course Title: iHRIS Administrator – Level I**

**Target Audience:** IT administrators

**Cource Description/Purpose:** This course is intended to provide an IT administrator the basic skills needed to install, maintain and customize the iHRIS Suite of software. In addition, this course will include an introduction to the LAMP (**L**inux, **A**pache, **M**ySQL and **P**HP) architecture, installation and administration of an Ubuntu system.

**Learning Objectives:** Upon successful completion of this course, students should be able to install Ubuntu and the iHRIS software, learn how to get assistance from the iHRIS developer community, understand and apply the iHRIS data model with respect to data standards, know how to build custom reports, be able to perform basic customizations, and work with the iHRIS translation system.

**Technical Requirements:** A relatively new computer on which to install Ubuntu, either natively or through a virtual machine. Should contain at least 1GB of RAM and 30GB of free hard-drive space.

**Educational Recommendation:** Bachelors degree in computer science, information technology, or the equivalent.
