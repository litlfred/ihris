# Adding Forms

## 1. Adding Forms

This module outlines an example of adding a new form to iHRIS Manage including:

- creating a module to contain functionality
- creating a form
- adding fields to the form
- relating the form to other forms

## 2. Gather Requirements

Discuss the client's information needs to determine the form requirements:

- example: an HR manager requests information on the dependents for each employee, including the name and birth date

The next step is to develop a use case based on these requirements.

## 3. Form Use Case

1A. Use Case Number: DEP-1

1B. Use Case Title: Add Person's Dependents

2. Level: User-level

3. Primary Actor: HR Staff

4. Context of Use: The user adds information about a person's dependent to the system

5. Preconditions: The user must be logged in and a personnel record must be visible

6. Success Guarantee: The dependent is added to the system and can be seen in their personnel record.

7. Main Success Scenario (MSS):

1. The user chooses to add a new dependent to the system

2. The user adds the dependent's name, date of birth and gender

3. The user saves the record

4. The dependent is now shown in the personnel page

## 4. Form Use Case

8. Extensions:

1a. The user chooses to edit the information on an existing dependent

2a. The system determines that no name is set for the dependent

1. The system displays an error message

## 5. Creating a Module for Forms

Adding and editing the example "dependents" in the system is a discrete function and should be put in a module:

- in this case, this new module should be dependent on the person module
- you need to define the form created (the dependent form)

The module will need an associated module class that shows "dependents" in the "view person page".

## 6. Creating a Module for Forms

Create a submodule of the site.

Create module via file configuration.xml:
 **sudo chown -R
 `whoami`:`whoami` /var/lib/iHRIS/sites/manage
 cd /var/lib/iHRIS/sites/manage/modules
 mkdir dependent
 cd dependent
 gedit dependent.xml**

The path /var/lib/iHRIS/sites/manage may be different depending on your installation.

## 19. Existing Dependents

Child forms of person are displayed using "iHRIS\_PageView".

It looks for a fuzzy method for the "iHRIS\_PageView" class named "action\_mydependent()".

"My\_Module\_Dependents" should implement "action\_mydependent()" for "iHRIS\_PageView".

## 20. Module Class

modules/dependents/lib/My\_Module\_Dependents.php:
class My\_Module\_Dependents extends I2CE\_Module {
/\*\* register a fuzzy method to display dependents on the view person page \*/
function getMethods() {
return array('iHRIS\_PageView-&gt;action\_mydependent'=&gt;'show\_dependents');
}
function show\_dependents($pageObject) {
$pageObj-&gt;addChildForms('mydependent');
return true;
}
}

If "$this-&gt;action\_mydependent()" is called in "iHRIS\_PageView", then "show\_dependents()" is called with the "$pageObject" as its first argument.

## 21. Module Class

The method addChildForms('mydependent') is a method of iHRIS\_PageView which:

- looks for the html "$node" with id "mydependent"
- populates all of the child forms "mydependent" of the "person" form
- for each "mydependent" form adds the HTML template file "view\_mydependent.html" and associates the mydependent form for that node

## 26. Editing Dependents

Editing an existing dependent and/or creating a new dependent requires a page.

There is a page class "iHRIS\_PageFormParentPerson" that handles editing forms which are child forms of the parent form:

- register the dependent page as a top-level page using **HRIS\_PageFormParentPerson**
- create the **form\_mydependent.html** HTML template used by this page

## 27. Registering the Page

Add a new section to dependent.xml:

&lt;configurationGroup name="dependent\_page" path='/I2CE/page/mydependent'&gt;
&lt;configuration name="style" values="single"&gt;

## 30. Commit to Bazaar (bzr)

Once you finish making the changes:

- test the module
- check "bzr status" to see which files were edited
- add the files to nzr: bzr add modules/dependent
- commit the files to bzr: bzr commit -m "adding a dependents module"

## 31. Adding Additional Form Fields

To add another field to the form such as dependents' favorite colors:

- increase module's version to 4.0.3.1
- add a "&lt;version&gt;4.0.3.1&lt;/version&gt;" where the favorite color field has been added
- adjust the HTML template files
- test it
- commit the changes to bzr/launchpad: bzr commit -m "added the favorite color field to dependent form"
