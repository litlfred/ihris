# Data Value Lists (video transcript)

In this video, I will show you how to update data value lists in iHRIS. These data value lists often appear as drop down lists when the user is entering or editing information. It is important to ensure standardization of data value lists in any information system. For iHRIS, data value lists make sure data adheres to specific standards defined by HR management. That means data can be aggregated into meaningful reports that HR managers and other health decision-makers can then analyze to answer a wide variety of key policy and management questions.

In iHRIS, administrators or HR managers can update data value lists. There are a number of lists that can and should be customized for your organization such as those dealing with jobs, like a health workers cadre or salary grade, or organization lists, like facility type or department. Facility type is important when iHRIS is deployed at the central level, like at a Ministry of Health that uses iHRIS Manage to aggregate information on health workers working at diverse locations. This is also true for professional health councils that use iHRIS Qualify to track information on health professionals deployment.

Now I will show you how to update the Facility type. I am logged in as Administrator and am on the home page of iHRIS Manage. First, I click on “Configure System” and then I click on “Administer Database.” Under Organization Lists, I click on “Facility Type.” And now you can see the current types of facilities that have been entered into iHRIS Manage already, including Clinic, Community Health Center, and Dispensary. I can either edit one of these existing options or I can add a new Facility Type.

Now, let’s say I’m working at a Ministry of Health that oversees both district hospitals and regional hospitals. That means the current Hospital option here is not sufficient. Therefore, I can edit Hospital and change it to District Hospital and I can also add a new Facility Type called Regional Hospital. So let’s edit Hospital by clicking on “Hospital” and then clicking on “Update this Information.”

So under Name, I just add: District. And you see there is a Hide field here but we’re going to leave that as no. Only Administrators see this Hide option. iHRIS developers did this because deleting data in the system is complex and one needs to be careful when deleting any data in value lists because other data may refer to the list. So this Hide field is a compromise measure. The data still remains in the system so it is still valid. So let’s click “Confirm” and “Save.” Now we’ll “Select another Facility Type” and we will “Add new Facility Type.” Under Name, I’ll type: Regional Hospital and click “Confirm” and “Save.” We go back to our list and we’ll now see that we have the District Hospital option and the Regional Hospital option. So now you’ve learned how to update and edit value lists.
