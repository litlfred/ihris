# iHRIS Administrator - Level I, Moodle course (`ihris-admin-course`)

<p><img src="../../src/site/theme/intrahealth-logo.png" alt="IntraHealth International" width="170"></p>

**iHRIS Administrator – Level I, © IntraHealth International, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).** Originally offered at <http://www.hrhresourcecenter.org/elearning> (CapacityPlus).

*iHRIS Administrator - Level I* (shortname *iHRIS Admin 1*) is an e-learning course made for IntraHealth International's CapacityPlus project and run on the HRH Global Resource Center, created in January 2011. Its 27 lessons run from an introduction to HRIS and installing Ubuntu and iHRIS, through modules, magic data, forms and custom reports, to translation, Launchpad and Bazaar, use cases and adding forms. The owner uploaded a **Moodle 1.9.9 course backup** of it, taken 2012-08-12, on 2026-10-09. The zip is in `uploads/ihris-admin-course/`, which is git-ignored; [`manifest.json`](../../uploads/ihris-admin-course/manifest.json) pins it by size, MD5 and SHA-256.

## Not published

- **The slide audio** (40 mp3 files, 16 MB): inventoried in `course.json` with its sha256, not committed because of its size. Where a lesson page links to one, the text says so.
- **The transcripts as Word files**: their text is here; the `.doc` files stay in `uploads/`.
- **Personal data.** The backup holds no users and no user data (`USERS none`, every module's `USERINFO false`), so there are no posts, attempts or responses; the ingester refuses a backup that has any. The images were reviewed one by one with the owner (2026-10-09). One, a photograph of a child, is not copied: it is listed in `course.json` (`withheldImages`) and the page that showed it says so. Five screenshots are published with a part painted over: a third party's name and machine in the Ubuntu installer screenshots become "Demo User" and "demo-virtual-machine" (owner: "change falko"), and the owner's e-mail address in the iHRIS user form becomes an example.org address ("remove my email"); each is marked `redacted` in `course.json`, with the source's sha256. Public user handles (Launchpad translators, pastebin) are kept ("keep public user handles"), and so is the example data in the forms lesson ("demo data"). The course overview's development team, other than the instructor, is not named. The certificate's settings, which name a contact address, are not read, and any e-mail address in the text would be removed (none was).
- Two images the lesson *Translating iHRIS* shows are not in the backup (`missingImages`).

QA (`moodle-course` in `src/tools/qa.py`) checks the counts against the records and the manifest, that every section's modules resolve, that every content file and image exists at its sha256 and nothing else is there, that every image a module shows resolves and no withheld image is published, that the licence is the declaration's, and that no e-mail address is present.

## Relation to the rest of this folio

The course's lessons cover much of what [the 2010 Administrator Handbook](../ihris-admin-handbook/) and [the iHRIS wiki](../ihris-wiki/) document, and its *Use Cases* lesson teaches the method of [the 2009 use-case model](../ihris-use-cases/). No crosswalk to them is derived here.
