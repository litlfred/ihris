Internet Relay Chat

1. Internet Relay Chat (IRC)

In this module, you will learn how to log into Internet Relay Chat (IRC). This is an important first step to joining the iHRIS development and support community.

2. Internet Relay Chat - IRC

Internet Relay Chat (IRC) is an instant messaging system that existed before Skype, Yahoo IM, or Microsoft Messenger.

IRC is a good source for technical support, especially within the open source community.

3. IRC Terminology

IRC Server: the computer to which you are connecting example: irc.oftc.net

IRC Channel: the name of the forum or group you wish to contact—each channel has a specific topic example: #ihris

IRC Client: the program you are using for your chat example: IceChat, xchat-gnome, or the iHRIS IRC Chat

4. IceChat

This is the best IRC client for Windows users.

To connect to IceChat:

  • go to: http://www.icechat.net/site/downloads/
  • choose the "IceChat Full Install"
  • in the input box type: /server irc.oftc.net /join #ihris /nickname <NAME>
  • replace <NAME> with a one-word nickname

5. xchat-gnome

Ubuntu users can use xchat-gnome IRC client. Open a terminal and enter: sudo apt-get install xchat-gnome

To access it, go to "Applications" then "Internet" on your computer.

Connect to the IRC server under XChat's toolbar:

  • click "IRC Connect"
  • select "OFTC"
  • click "Connect"

Join the IRC channel under XChat's toolbar:

  • click "Network Join Channels"
  • type: #ihris
  • select "Join Channel"

6. iHRIS IRC Chat

This IRC client is web-based, so it does not have an operating system requirement.

It only supports the iHRIS community of users.

Connect to it at: http://open.intrahealth.org/mediawiki/Special:PJIRC
