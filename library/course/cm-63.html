Updating iHRIS

iHRIS Administrator - Level I, © IntraHealth International, CC BY 4.0. Originally offered at hrhresourcecenter.org/elearning (CapacityPlus). Licence stated by its author, the folio owner, 2026-10-09.

1. Updating iHRIS

The iHRIS Software has periodic releases to:

  • fix reported bugs
  • add new functionality
  • add and update translations to the software

Strategy to update your software regularly:

  • backup your test server
  • perform the upgrade on your test server
  • ensure that upgrade went smoothly on the test server
  • backup your production server
  • next perform the upgrade on your production server

2. Updating iHRIS

The instructions will vary depending on the installation. This tutorial assumes the administrator:

  • installed version 4.0.5 of the software
  • will be upgrading to version 4.0.10
  • installed the demo site under var/lib/iHRIS/sites/manage/

3. Downloading iHRIS

Begin the iHRIS update by downloading the current version of iHRIS. The most current version can be found at: https://launchpad.net/i2ce

You will be downloading a tarball such as: ihris-suite-4_0_10.tar.bz2

4. Updating the Main Code

Move the old iHRIS code: sudo mv /var/lib/iHRIS/4.0.5 /var/lib/iHRIS/4.0.5.old

Make a directory for the new code: sudo mkdir /var/lib/iHRIS/4.0.10

Extract the tarball to the "4.0.10" directory: cd /var/lib/iHRIS/4.0.10 sudo tar -xjf ~/Desktop/ihris-suite-4_0_10.tar.bz2

5. Updating the Site

If you are upgrading from a version prior to 4.0.9, update the site's module to the new demo code: sudo gedit /var/lib/iHRIS/sites/manage/iHRIS-Manage-Demo.xml

Remove the <value>../../../</value> by changing: <path name="modules"> <value>./modules</value> <value>../../../</value></path> to: <path name="modules"> <value>./modules</value> </path>

6. Updating the Site

Point the site's module to the new demo code: sudo gedit /var/lib/iHRIS/sites/manage/pages/local/config.values.php

Change: /** * the path to the I2CE installation. * You might need to set this depending on your installation * Default value is ../../../../I2CE */ $i2ce_site_i2ce_path = "/var/lib/iHRIS/4.0.5/I2CE";

to: /** * the path to the I2CE installation. * You might need to set this depending on your installation * Default value is ../../../../I2CE */ $i2ce_site_i2ce_path = "/var/lib/iHRIS/4.0.10/I2CE";

7. Checking Updates

Browse to: http://localhost/manage to check the updates
