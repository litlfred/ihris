Create a Report Relationship (video transcript)

iHRIS Administrator - Level I, © IntraHealth International, CC BY 4.0. Originally offered at hrhresourcecenter.org/elearning (CapacityPlus). Licence stated by its author, the folio owner, 2026-10-09.

iHRIS has a custom reporting system that enables you to develop new reports based on the data in the system. There is an iHRIS datamap on the iHRIS wiki that shows how all the data is related in the system. It’s a good idea to familiarize yourself with the datamap as you will need to refer to it when you create a custom report. Building a custom report in iHRIS is a three part process. First, we create the form relationship, creating directions to navigate the data map. Second, we create the report, determining what data to use from the map. Third, we create the report view, displaying the selected data. In this video we will focus on creating the form relationship.

Let’s say someone from the Ministry of Health asked us to create a staff list showing each employee’s cadre and the facility where they work. First, we need to determine what data is needed and where it is stored. To make the required report, we need to include the following forms: the facility, to find the name of the facility; the job form, to find the cadres; and the person form. Although not expliectly stated as a requirement, assume that the names of the staff will aid in organizing the report. So, we start by creating a new form relationship called “Staff Info.”

After logging in as administrator, we are now on the homepage of iHRIS. We click on “Configure System.” Under Manage Reports, we go into the “Form Relationship” menu. Now we want to create a new relationship called Staff Info. The Relationship Short Name is how we will refer to the relationship later on in the reports and report views. Under Relationship Short Name, we enter: staff underscore info [staff_info]. The relationship short name is something used internally by the system and the nonadministrative end user does not need to see it. What the nonadministrator will see is the Display Name, so we will put a more user-friendly name under Display Name. Under Display Name we will enter: Staff Info. And for Description enter: Staff info relationship for demonstration purposes.

Now we need to choose what the primary form of the relationship is. We choose Person as the primary form. To the right we now see that the Person Form holds the basic information about a person such as their names and their residence, so we know we’re in the correct place. We’re not modifying an existing relationship so we don’t need to copy it. Now click “Update” to create the relationship.

Now that we have created the relationship, you can see it listed under Edit an Existing Relationship as Staff Info. So now we need to edit it. Click “Edit” an existing relationship.

If we were looking at the form map, we would see that the Person Form is linked to the Person Position Form. So now we need to add, or join, the Person Position Form to the Person Form so we go to “Joined Forms” and click on “Add a new child form.” Here we select the Person Position Form. It is being added as a Child of the Person Form. The Short Name is: person underscore position [person_position] and this is just a way to reference this Person Position Form in the form relationship. The Display Name is: Person’s Position. The Description is: the current position that a person holds. So once we’ve entered all this, we click “Add” to add this into our form relationship. Now, when we click back on the “Joined Forms,” you will see that we’ve now joined the Person Position form.

Now that we’ve added the Person Position Form, there are some slight differences prior to iHRIS 4.09 and after 4.09 in the way it looks but they aren’t significant. If we click on the “Person Position Form” under Existing Joined Forms, additional options for that specific Person Position Form appear. This is where we are going to join in the Position Form itself. We have some options to limit this form and linking this form. We won’t be dealing with linking this form in this module but when you are making an establishment report, you will need to worry about linking forms.

We now need to limit the forms in our form relationship because each person may have held multiple positions and we only want to pull out the most recent one. So, we click on “Limit this form.” Since we only want people who are currently employed, we need to make sure that there is not an end date set for the position being held. To do this, we will need to add in two limits to this form: one, the start date for the position is the maximum date of all the positions held and two, the end date is blank, or null.

The first step is to add a little logical operation, which is called an AND clause, as we have two limits to add. Under Choose Limit Node Type, change the radio button to “Operator Node” and from the dropdown menu select “AND.” Now click “Update.” Now we need to add a new operand, which are the conditions we are setting, the maximum start date and the null end date. To add an operand, we click “Add.” Now we go in and click “Edit” and we will change the radio dial to “Limit by a field.” And click “Update.”

So again, for our first limit, we want to limit the start date so under Form Field, choose “start date.” For the Field limit style, choose “max_parent.” On my screen you see some additional options appear. If you are using iHRIS 4.0.7 or earlier, you won’t see these additional options appear and that’s ok, you don’t need to worry about it. If you do have 4.0.7 or after, the limit on this field should be set to “Parent.” In other words, we want the start date to be the maximum start date for all the start dates of that particular parent which in this case was the person. We now click “Update.”

We now need to add the second limit which is the end date. So we click “Add” and for the second limit, we set the form field to “end date” and set the Field limit style to be “null,” which means it will be left blank. In other words, if the person has not left their position, then there can be no end date. Now we click “Update.” And we’ve now set the limit for the person position form.

Now that we have the most current position, we can go ahead and add in the position information and then the facility and the job information. So we’ve got the Person Position Form, we’ve looked at the joined forms, and we need to add in the Position Form from the person_position form. To do this, we click on “Joined Forms” and “Add a child form.” You can see here that there are fewer forms to link than when we had the person form because there are not many forms that link into the person_position form. So we choose the “position.” Our short name is: position and the display name is: position and the description is: The position this person holds. Now we click “Add.”

Now we go down and see under “Joined Forms,” and “Existing Joined Forms,” the Position. Now that we’ve joined in the Position, we finish by joining the Facility and Job Forms. The first form we will join is the Job Form. The short name is: job. The display name is: job and the description is: the job associated with the person’s position. And we click “Add.” Now we also need to add in the facility which we do by selecting “Add new child form.” Here we select “Facility” and the short name and display name can be: facility with a description of: The facility where the position is at. Now we click “Add” and we have just created our staff info form relationship and we have all the data that we need in there.

Create a Report (video transcript)

As you learned in the previous video, creating custom reports is a three part process. First we create the form relationship, creating directions to navigate the datamap. Second, we create the report, determining what data to use from the map. Third, we create the report view, displaying the selected data. In the first video, we created the form relationship. In this video, we will focus on creating the report.

So the report is actually what pulls the data out of different forms and puts it into a nice table in the database that we can view and run queries against. Right now we’re still logged in as Administrator and we’re on the home page. We click on “Configure System.” Then under Manage Reports, we click on “Reports.” What you see now are the existing reports in the system and you can create a new report down at the bottom which is what we want to do. The shortname is a way to reference the report. In this case, we’re going to stick with: staff underscore info [staff_info]. The relationship that we’re using is the Staff_Info that we set up in the previous video. The Display Name can be: Staff Info -- Demonstration. You are free to choose whatever you want for a category. You don’t have to stick with an existing category which are shown up here in blue such as Staff Reports or Search. For this example, we’re going to use the Staff Reports category that already exists which means it will show up under the Staff Reports label. Let’s make description: Staff Info Report for Demonstration. And now we create the report by clicking “Update.”

You can see the report we just added under Staff Reports. Here it is–Staff Info Demonstation. Now we need to specify what data we want in the report so we click on “Edit.”

The Report Information has the metadata that we just added - the display name, category, and description. So let’s click on “Reported Forms.” These are the forms we added into our form relationship in the first video. Here’s our staff info which was the primary form and the person form. This is the person position form with the position, facility, and job forms. So if we click on “Staff Info” and open the reported fields, we can see various fields that can be added to the report. Let’s go ahead and add the First Name by checking on “Enable.” Let’s also scroll down and add the Surname field. Now, if we want to link this person’s name to their record, then we need to set up links. To link their first name, click on the plus sign [+] next to Link Options. The link page is the view page and the link field is the person’s ID. So in the Link URL field, type: view?id= and set the Link Field to the “Primary_Form Id.” To link their last name, you do the exact same thing under Surname. So I’m typing: view?id= and I’ll choose “Primary_Form Id.”

If you want to be able to search on a person’s surname, then you would look at the “Limit Options” in the Person Surname box. This reveals various SQL statements. So let’s click on “Limit Options” and scroll down. Contains is the one that we want so let’s check the box next to “Contains” and we’ll rename the limit by typing: Surname/Lastname. When we are looking at a report view, this will be one of the fields that we can limit by. What the SQL will actually be doing is looking to see if the surname you type in is contained in the actual surname. So if you type Mc, you’d find McDonald and McCaffy and so on.

Now let’s look at the other information we want to put in this report. Let’s scroll down and under Person Position, click on “Person Position” and click on “Reported Fields.” We can scroll down more and “Enable” the Start Date and click on “Limit Options” and limit it to only show those after a certain date by checking “Greaterthan Equals” and renaming it: Commenced Employment. When you look at at the report view, you’ll be able to limit by the start date of the position.

Now we can scroll down again and click on “Position” and “Reported Fields” and here we can add the Position Title. So I’ll scroll down again and click on “Enabled” next to Title. We can also add the name of the facility by clicking on “Enabled” next to Facility. So I’m scrolling up and clicking on “Enabled.” While we’re here, let’s also add the ability to limit by the facility location by clicking on “Limit Opotions” and selecting the Limit Style “Equals” and renaming it: Location of Facility.

So we’ll scroll down again. Under Job, click on “Job” and “Reported Fields.” Let’s choose to enable the Title and the ISCO codes. So I’ll click on “Enable” next to Title and “Enable” next to ISCO 08 Codes. You see we also have Cadre which is a good option for limiting so let’s “Enable” Cadre and click on “Limit Options” and selecting “Equals” and we’ll rename it: Cadre.

Once you’ve selected everything you want to appear on the report view, select “Update.” Now we have our Staff Info report set up.

So if we go back to the Reports overview by clicking on “Reports” in the left hand toolbar, we can see that the staff info has already been generated but we’ve just made some changes. We need to re-generate it by clicking on “Generate (Forced).” If you look in the database, this will be the zebra staff info table.

Create a Report View (video transcript)

In the previous video, we created our staff info report based on the staff info form relationship. This also create the zebra staff info table in the database. Now we want to set up different report views of that table. We’re still logged in as administrator so we’ll click on “Configure System” and then click on “Report Views.” Here we see all of the existing report views but we're going to create a new report view of the staff info report. You can have as many views as you want. You might want to have one view that shows the person’s name and the facility and another view that shows the person’s name, facility, and their job. Based upon the data that’s in that table already, you can just select nice little views of it.

For the name of the view–there is no short name, no internal name, there is just the display name– which is: Staff Info Demonstration. Next, we need to choose the report. In this case, we need to pick the “Staff Info–Demonstration” and also add a description which is: List of current staff with facility and cadre. Now we click “Update.”

Now if we go under our staff reports, we should see Staff Info Demonstration. There it is. If you click on the link, you will be able to view it although right now, it won’t show up with anything as we haven’t yet selected the fields to display. So we need to edit the view by clicking on “Edit” beneath the title.

If we had not clicked edit, another option is to “Archive Report.” So if you wanted to save a report on a monthly basis into the system, you can click this “Archive Report” link. But since we’ve already clicked on “Edit,” you will see the metadata that we’ve already set up. To select the fields we actually want to go into the report view, you merely check the box next to the field title. We want to see the First Name, the Surname, Facility Name, Cadre, and the ISCO Code along with the start date. Now we click “Update” again.

Now we should be able to view the staff info report. We have the first name, the surname, the start date, the facility name, and cadre. If you want to reorder how the reports are displayed, click on “Configure System” and click on “Report View”. Now click on “Edit.” Under the Reported Fields, you click on the field you want to move and drag it to where you want it to be before dropping it. So here we want our Facility to be moved. And now we “Update” and “View the report” again.

You can choose any of the options at the bottom to limit the results shows. Once you have modified your limits, you need to click “View” in order to update the view. So we can change location of facility to be “Capital City Hospital.” And click “View.” And now you see results only pertaining to Capital City Hospital. If we scroll down again, you can see that you can also “Print” the report and “Export” it to Excel. And now we have successfully created our report view.
