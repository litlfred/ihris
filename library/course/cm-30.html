Question 1 (match)

As an iHRIS administrator, you will benefit from working with other developers in the Open Source community and using a number of collaborative online tools. Match the following tools with their definitions.

statement answer
An instant and open messaging system that is a good source for technical support, especially within the Open Source community. IRC
The website that hosts the iHRIS code and facilitates management of translations into other languages. Launchpad
A website designed for developers to share code and error messages. Pastebin

Question 2 (match)

Match the following iHRIS-related terms or acronyms with their definitions.

statement answer
The web framework on which the iHRIS software is built I2CE
A pair (language, country) used in the iHRIS software to keep track of translations in various languages Locale
The architecture used for many web-based programs such as Moodle LAMP
Free software used for version control Bazaar
The place in the iHRIS software which holds information about modules, pages, forms, and reports Magic Data
Documents used in development to describe a work process Use Cases
A format developed by the World Health Organization to facilitate the exchange of indicator definitions and data between information systems SDMX-HD
