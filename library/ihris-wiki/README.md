# iHRIS wiki (`ihris-wiki`)

The iHRIS wiki (first at `open.intrahealth.org/wiki`, named *Osi*, later `wiki.ihris.org`) is where most iHRIS documentation lived. Neither host is reachable from the session that built this, so it is being **restored from surviving copies**.

## Restored so far

**[`osi-help-4.3.3/`](osi-help-4.3.3/)**: 44 wiki pages, the iHRIS Manage and iHRIS Qualify *User Manual*, as they were exported into the built-in help modules of iHRIS 4.3.3 (`manage-help`, `qualify-help`). They are converted to Markdown, one section per page. Where the Manage and Qualify copies of a page differ, both are kept as variants (61 sections in all). Each section's front matter says which package shipped it. Licence: GPL-3.0, as part of the iHRIS source.
